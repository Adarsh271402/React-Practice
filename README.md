# React Frontend Practice

[Live Demo](https://react-practice-adarsh.netlify.app)

Ten interview-style mini projects in one Vite + React app:

1. Calculator
2. Todo App with localStorage
3. Weather App using Open-Meteo
4. Image Gallery with lightbox
5. Responsive Navbar
6. Accordion
7. Modal Popup
8. Login Form with validation
9. Product Search
10. Pagination

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
